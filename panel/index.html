Pick a Short, pick a day, done. Your Reel goes live at the time you choose, with your pinned comment – all running in the cloud for free on GitHub Actions. No code, no terminal. First, connect this panel to GitHub once.

  1. Create an empty private repository on GitHub

    Just enter a name (e.g. shorts-to-reels), choose Private and click Create repository. Leave everything else as it is.

    Open github.com/new ↗
  2. Create an access token (fine-grained token)

    Repository access: Only select repositories → pick your new repository. Set the longest expiration available. Under Repository permissions set:

    • Actions, Contents, Secrets, Variables, Workflows: Read and write
    Create token ↗
  3. Paste the token and repository

Next, a short checklist walks you through the rest: upload the project → add your API keys → pick your channel & publish time → run a test.
